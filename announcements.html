# UHH Secure Backend / Discord Sync GitHub Pages cannot securely verify Roblox OAuth, protect staff-only data, or read Discord channels because all frontend code is public. This backend is the safe place for secrets. What it is designed for: - Real Roblox OAuth login callback. - Checking logged-in Roblox users against your staff database. - Verifying HCPC PIN server-side. - Discord bot access to the vacancies channel `1511950462058889326`. - Website up/down checks sent to your Discord webhook. Setup: 1. Run `npm install`. 2. Copy `.env.example` to `.env`. 3. Add your real Discord bot token, webhook URL, and Roblox OAuth app details. 4. Invite the Discord bot to your server with permission to read the vacancies channel. 5. Run `npm start`. Important: the included frontend is a localStorage prototype. For a real staff portal, connect this backend to a real database such as Supabase, Firebase, SQLite, or PostgreSQL.
